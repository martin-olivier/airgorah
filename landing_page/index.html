WiFi Security Auditing Made Simple

Airgorah - A powerful, open-source WiFi security auditing tool built with Rust and GTK4

Get Started View on GitHub

Powerful Features

📡

WiFi Traffic Capture

Capture and analyze nearby WiFi traffic with ease. Monitor all wireless communication in real-time.

🔍

Client Discovery

Discover all clients connected to access points. Identify devices on your network with detailed information.

⚔️

Deauthentication Attacks

Perform controlled deauthentication attacks for security testing on networks you own.

🤝

Handshake Capture

Capture WiFi handshakes for advanced password analysis and security assessment.

🔐

Password Cracking

Advanced password cracking capabilities based on aircrack-ng, one of the most trusted tools in security.

🛡️

Security Testing

Comprehensive security testing suite to identify vulnerabilities in your WiFi networks.

How It Works

1

Install Airgorah

Download and install Airgorah on your Linux system with a single command.

2

Configure Network Card

Ensure your wireless card supports monitor mode and packet injection.

3

Launch the GUI

Start the intuitive GTK4 interface and begin your security audit.

4

Analyze & Test

Capture traffic, discover clients, and perform security tests with ease.

Quick Installation

Via Cargo (Recommended)

cargo install airgorah

Via AUR (Arch Linux)

yay -S airgorah

Via Docker

docker build -t airgorah .

System Requirements

  • ✓ Linux operating system (Wayland or X11)
  • ✓ Wireless network card with monitor mode support
  • ✓ Packet injection capability
  • ✓ sudo/polkit for privileged operations
